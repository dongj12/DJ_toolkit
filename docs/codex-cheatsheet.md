# Codex CLI 치트시트

명령 목록은 2026-10 기준 Codex 소스(`codex-rs/tui/src/slash_command.rs`)에서 확인했습니다. 응시 환경의 버전에 따라 다를 수 있으니 `/`를 입력하면 나오는 목록을 기준으로 하세요.

## 자주 쓰는 명령

| 명령 | 하는 일 | 언제 |
|---|---|---|
| `/status` | 현재 모델, 권한, 토큰 사용량 | 시작할 때, 중간 점검 |
| `/model` | 모델과 추론 강도 선택 | 시작할 때 (권장: Sol 6.1) |
| `/permissions` | Codex가 승인 없이 할 수 있는 범위 | 승인 요청이 너무 잦을 때 |
| `/skills` | 설치된 스킬 목록 | 툴킷 설치 확인 |
| `/mcp` | MCP 도구 목록 | MCP 설정 확인 |
| `/diff` | git 변경 내용 (추적 안 된 파일 포함) | 커밋 전에 확인 |
| `/review` | 현재 변경에서 문제 찾기 | 기능 완성 후, 제출 전 |
| `/plan` | 계획 모드로 전환 | 큰 작업을 시작하기 전 |
| `/compact` | 대화를 요약해 컨텍스트 확보 | 대화가 길어져 느려질 때 |
| `/new` | 새 대화 시작 | 주제가 완전히 바뀔 때 |
| `/mention` | 파일 지정 | 특정 파일을 보라고 할 때 |
| `/ps`, `/stop` | 백그라운드 터미널 보기, 모두 중지 | 서버가 여러 개 떠 있을 때 |
| `/quit` | 종료 | 스킬·규칙을 새로 읽게 할 때 (다시 `codex`) |

`/init`은 쓰지 마세요. 작업 폴더에 AGENTS.md를 새로 만들어 제출물에 섞입니다.

## 입력 요령
- `$스킬이름` 으로 스킬을 직접 부릅니다. 예: `$dj-kickoff 과제 README 분석해줘`
- `@파일명` 으로 파일을 짚을 수 있습니다.
- Enter 전송, Shift+Enter 줄바꿈, Esc 응답 중단.
- 승인 요청이 뜨면 기다려도 진행되지 않습니다. 내용을 보고 승인하거나 거절하세요.

## 상황별 한 줄 요청

| 상황 | 요청 |
|---|---|
| 시작 | `$dj-kickoff 과제 README 분석해줘` |
| 결정했을 때 | `$dj-decision-log 방금 결정 기록해줘` |
| 기능 완성 | `$dj-verify 테스트하고 서버 띄워서 확인해줘` → `$dj-checkpoint` |
| 미리보기가 안 열림 | `$dj-verify 미리보기가 안 열려. 포트랑 바인딩 확인해줘` |
| 코드 이해 | `이 코드 핵심을 3줄로 설명해줘` |
| 20분 남음 | `$dj-submit-check` |
| 제출 직전 | `$dj-explain` (5분 동안 읽기) |
